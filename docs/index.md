# Документация GoMax

Добро пожаловать в официальную документацию библиотеки **GoMax** — высокоскоростного Go-клиента для взаимодействия с внутренним API мессенджера Max.

Библиотека разработана как полноценный, идиоматичный порт Python-библиотеки [PyMax](https://github.com/MaxApiTeam/PyMax), обеспечивающий 100% совместимость протокола, сохранение всех сигнатур методов, нативную поддержку авторегистрации новых аккаунтов и непревзойденную производительность для высоконагруженных сценариев и мультиаккаунтинга.

## 📚 Разделы документации

### 🚀 [Быстрый старт](getting-started.md)
Установка библиотеки, требования к окружению, инициализация первого клиента и пример простого эхо-бота.

Подробный справочник по параметрам структуры `Config`: настройка эндпоинтов, портов, таймаутов, SOCKS5/HTTP прокси, параметров повторного подключения и параметров сессии.

### 🔐 Авторизация и безопасность
- [SMS-авторизация](authentication/sms.md) — вход по номеру телефона, получение и подтверждение SMS-кода, работа с SMS-сервисами.
- [QR-авторизация (веб)](authentication/qr.md) — авторизация через сканирование QR-кода мобильным приложением.
- [Двухфакторная защита (2FA)](authentication/2fa.md) — обработка облачных паролей и управление 2FA.

### 💾 Хранилище сессий (Persistence)
- [SQLite хранилище](session/sqlite.md) — сохранение сессий в базе данных SQLite (рекомендуется для сотен аккаунтов).
- [Файловое хранилище JSON](session/file.md) — простое локальное сохранение в файлы.
- [Хранилище в памяти](session/memory.md) — работа без сохранения состояния на диск.

### 📡 Справочник API (Методы сервисов)
Каждый раздел содержит детальное описание сигнатуры, аргументов, возвращаемых типов, внутренних опкодов и примеры кода для каждого метода:
- [Сообщения и реакции (`client.Messages`)](api/messages.md) — 17 методов: отправка, редактирование, удаление, пересылка, реакции, получение сообщений, отметки о прочтении, история чатов, опросы, медиа.
- [Чаты, группы и каналы (`client.Chats`)](api/chats.md) — 16 методов: вступления по ссылкам, инвайтинг участников, создание групп, выход, права, настройки, заявки на вступление (JoinRequests).
- [Пользователи и безопасность (`client.Users`)](api/users.md) — 14 методов: получение профилей, поиск по телефону, список контактов, активные сессии, сброс сессий, смена профиля.
- [Загрузка медиафайлов (`client.Uploads`)](api/uploads.md) — 4 метода: загрузка фотографий, видео, голосовых сообщений и файлов через multipart/form-data.

### ⚡ [События и фильтры](dispatch/events.md)
