# Документация GoMax

Добро пожаловать в официальную документацию библиотеки **GoMax** — высокоскоростного Go-клиента для взаимодействия с внутренним API мессенджера Max.

Библиотека разработана как полноценный, идиоматичный порт Python-библиотеки [PyMax](https://github.com/MaxApiTeam/PyMax), обеспечивающий 100% совместимость протокола, сохранение всех сигнатур методов и высокую производительность для высоконагруженных сценариев и мультиаккаунтинга.

---

## Разделы документации

### 🚀 [Быстрый старт](getting-started.md)
Установка библиотеки, требования к окружению, инициализация первого клиента и пример простого эхо-бота.

### ⚙️ [Конфигурация](configuration.md)
Подробный справочник по параметрам структуры `Config`: настройка эндпоинтов, портов, таймаутов, SOCKS5/HTTP прокси, параметров повторного подключения и параметров сессии.

### 🔐 Авторизация
- [SMS-авторизация (телефон)](authentication/sms.md) — вход по номеру телефона, получение и подтверждение SMS-кода, реализация собственных провайдеров (SMS-сервисы).
- [QR-авторизация (веб)](authentication/qr.md) — авторизация через сканирование QR-кода мобильным приложением.
- [Двухфакторная защита (2FA)](authentication/2fa.md) — обработка облачных паролей и управление 2FA.

### 💾 Хранилище сессий (Persistence)
- [SQLite хранилище](session/sqlite.md) — сохранение сессий в базе данных SQLite (рекомендуется для сотен аккаунтов).
- [Файловое хранилище JSON](session/file.md) — простое локальное сохранение в файлы.
- [Хранилище в памяти](session/memory.md) — работа без сохранения состояния на диск.

### 📡 Справочник API (Методы сервисов)
Каждый раздел содержит детальное описание сигнатуры, аргументов, возвращаемых типов, внутренних опкодов и примеры кода для каждого метода:
- [Сообщения и реакции (`client.Messages`)](api/messages.md) — отправка, редактирование, удаление, пересылка, реакции, отметки о прочтении, история чатов, опросы.
- [Чаты, группы и каналы (`client.Chats`)](api/chats.md) — вступления по ссылкам, инвайтинг участников, создание групп, выход, права и настройки.
- [Пользователи и безопасность (`client.Users`)](api/users.md) — получение профилей, поиск, список контактов, активные сессии, сброс сессий.
- [Загрузка медиафайлов (`client.Uploads`)](api/uploads.md) — загрузка фотографий, видео, голосовых сообщений и файлов через multipart/form-data.

### ⚡ [События и фильтры](dispatch/events.md)
Реактивная обработка входящих событий, регистрация обработчиков `OnMessage`, `OnStart` и цепочки предикатных фильтров сообщений.

### 🔌 [Протокол и транспортный уровень](protocol/wire.md)
Описание бинарного фрейминга Max (10-байтный заголовок), таблицы опкодов (114 RPC-команд), MsgPack кодека, алгоритмов сжатия (LZ4, Zstd) и эмуляции цифровых отпечатков устройств Android (`fingerprint`).

### 🤖 Рецепты для массовых действий
- [Масс-реакции](mass-actions/reactions.md) — пакетная расстановка эмодзи-реакций на посты с рандомизацией задержек.
- [Инвайтинг](mass-actions/inviting.md) — массовое добавление пользователей в каналы и чаты.
- [Вступления](mass-actions/joins.md) — автоматический переход по ссылкам-приглашениям.
- [Масслукинг (накрутка просмотров)](mass-actions/views.md) — отметка постов прочитанными.
- [Мультиаккаунтинг 100+ аккаунтов](mass-actions/multi-account.md) — параллельный запуск пула клиентов на горутинах с персональными прокси.
