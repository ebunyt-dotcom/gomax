# Примеры

Все примеры находятся в отдельных каталогах и используют модуль GoMax из корня репозитория.

| Каталог | Что показывает | Нужно изменить |
|---|---|---|
| quickstart | SMS-вход и echo-handler | Phone |
| sms_login | Явный SMS-клиент | Phone |
| qr_login | QR-вход через WebSocket | Ничего для базового запуска |
| events | Typed events и OnRaw | Phone |
| send_media | Загрузка фото и отправка | Phone, chatID, файл photo.jpg |
| profile_and_chats | Профиль и список чатов | Phone |

Перед запуском из каталога репозитория скачайте зависимости командой go mod download. Примеры выполняют настоящие сетевые вызовы: используйте собственный аккаунт и соблюдайте лимиты Max.
